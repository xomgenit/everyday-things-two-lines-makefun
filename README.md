## What it does

`main.ts` writes a two-line entry to `entry.txt` — an everyday-thing analogy
(a toaster as a tiny sun) that holds up, then honestly names where it stops.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
